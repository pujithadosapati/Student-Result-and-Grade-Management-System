## Student Result & Grade Management System
## Project Description
The Student Result & Grade Management System is a Python-based application used to manage student details, subject marks, grades, and academic performance.

It allows users to add, update, search, and view student records. It also calculates total marks, percentage, and grades automatically.
## Objectives
- Learn Python fundamentals.
- Understand functions and loops.
- Practice lists and dictionaries.
- Perform student record management.
- Calculate grades and percentages automatically.
## Technologies Used
- Python
- Programiz Online Python Compiler
## Features
1. Add Student Details
2. Update Student Details
3. Search Student Records
4. View All Student Records
5. Calculate Total Marks
6. Calculate Percentage and Grades
7. Generate Performance Summary
8. Validate Marks
## Grade Calculation
Percentage-Grade
90–100    - A+
80–89     - A
70–79      -B
60–69      -C
50–59      -D
Below 50   -Fail
## How to Run
1. Open Programiz Online Python Compiler.
2. Copy the Python source code.
3. Paste the code into the editor.
4. Click Run.
5. Select an option from the menu.
6. Enter student details and marks.
## Python Concepts Used
- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Dictionaries
- Exception Handling
- User Input and Output
## Expected Output
The application displays student details, subject-wise marks, total marks, percentage, grades, and overall performance summary.
